<!-- ─────────────────────────  INTRO  ───────────────────────── -->

**Senior Mobile Developer with 8+ years architecting and shipping production apps across Android, iOS, Flutter, and Kotlin Multiplatform.** I work natively on both platforms — Kotlin/Jetpack Compose and Swift/SwiftUI — and increasingly fold the shared logic into KMP so one codebase serves both. At **Kanguro Insurance** I integrated KMP into the existing native Android and iOS apps, hitting **~30% code reuse** distributed via Swift Package Manager. Before that I built features at brand scale: the **Play Disney Parks** app at Globant, fintech wallets (TodoPago, Smartpost/Credibanco), and the **Easy.cl** retail app at AcidLabs.

I care about the parts that outlast the first release: clean architecture, typed contracts, testable layers, and CI/CD that doesn't fight you. Lately I'm pairing that with AI-assisted developer tooling — including an open-source [Claude Code skill for KMP](https://github.com/felipechaux/kmp-compose-multiplatform-skill) that other developers have starred and forked.
